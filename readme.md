# Build output only

This branch is generated automatically. **Do not edit it by hand** — anything committed here gets overwritten by the next deploy.

Every push to the `source` branch triggers GitHub Actions to build the site and force-push the rendered `public/` directory here, which GitHub Pages then serves. That's why the history is a flat list of `Site updated: ...` commits.

Looking for the actual content? Go to the **`source`** branch: markdown posts, theme config and the build workflow live there, and its own readme explains how publishing works.
